# Car Rental Management System

A premium, modern client-side Single Page Application (SPA) translating an Oracle SQL database schema and PL/SQL business rules (triggers, packages, functions, cursors) into a dynamic web interface.

## 🚀 How to Open and Run in VS Code

### Step 1: Open the Project in VS Code
1. Open **Visual Studio Code**.
2. Click on **File** -> **Open Folder...** (or press `Ctrl+K Ctrl+O`).
3. Select this project directory:
   `C:\Users\ganey\.gemini\antigravity\scratch\car-rental-management`

### Step 2: Running the Web App

#### Option A: Run and Debug Panel (Recommended)
1. In VS Code, open the **Run and Debug** view on the sidebar (`Ctrl+Shift+D`).
2. At the top dropdown, select **Launch in Chrome (Direct File)** or **Launch in Edge (Direct File)**.
3. Click the green **Start Debugging** arrow (or press `F5`).
4. This opens Chrome/Edge directly to the application.

#### Option B: Live Server Extension
1. Go to the **Extensions** tab (`Ctrl+Shift+X`) in VS Code.
2. Search for and install **Live Server** (by Ritwick Dey).
3. Open `index.html` in VS Code.
4. Click the **Go Live** button in the bottom status bar, or right-click `index.html` and choose **Open with Live Server**.
