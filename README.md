# Car Rental Management System

Full-stack car rental management application built with **JavaScript, Node.js, Express.js, Oracle SQL, and PL/SQL**. The system manages vehicles, customers, rentals, payments, and staff operations through a multi-tier architecture.

### Highlights
- Developed frontend, backend, and database components of a full-stack application
- Built REST API endpoints and integrated them with an Oracle database
- Implemented vehicle, customer, rental, and payment management workflows
- Developed database procedures, functions, packages, and triggers using PL/SQL
- Applied data validation, business rules, exception handling, and debugging

### Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** Oracle SQL, PL/SQL  
**Tools:** Git, GitHub, Visual Studio Code

### Skills Demonstrated
Full-Stack Development · REST APIs · Database Design · Oracle PL/SQL · Backend Development · Debugging · System Integration
